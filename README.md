# 보물 찾기 퀴즈 — 실시간 교사 진행판

선생님이 교사 화면에서 문제를 하나씩 열면 학생 태블릿에 그 문제가 나타납니다.
학생은 풀고 나서(맞히면 보물 카드까지 고르고) 다음 문제가 열릴 때까지 기다립니다.
교사 화면에서 접속 인원, 문제별 제출 현황, 정답 여부·점수, 최종 순위를 실시간으로 봅니다.

## 주소

| 누가 | 주소 |
|---|---|
| 학생 | `https://<사이트 주소>/` → 방 코드 4자리 + 이름 |
| 교사 | `https://<사이트 주소>/teacher.html` → 퀴즈 고르고 방 열기 |

## 폴더 구성

```
live-quiz/
├─ index.html / student.js   학생 화면
├─ teacher.html / teacher.js 교사 화면
├─ common.js, style.css      공통 (채점, 그림, 저장소)
├─ firebase-config.js        ← Firebase 설정값을 붙여 넣는 곳 (한 번만)
├─ database.rules.json       Firebase 규칙 (콘솔에 붙여 넣기)
├─ make_index.py             퀴즈 목록(quizzes/index.json) 다시 만들기
└─ quizzes/
   ├─ index.json             교사 화면의 퀴즈 목록
   ├─ 4-2-4-평행선.js         문항 파일 (형식은 아래)
   └─ images/                사진 그림
```

## 수업 흐름

1. 교사: `teacher.html` → 퀴즈 선택 → **방 열기** → 화면에 방 코드(예: 4827)와 학생 주소가 나옴.
2. 학생: 주소 접속 → 방 코드·이름 입력 → "선생님이 문제를 열 때까지 기다려요".
3. 교사: 오른쪽에 들어온 학생 확인(초록 점 = 접속 중) → **문제 1 열기**.
4. 학생: 풀고 정답 확인(기회 한 번) → 맞히면 보물 카드 고르기 → "다음 문제를 기다려요".
5. 교사: 제출 막대와 학생 칸(파란 칸 = 제출) 확인 → 필요하면 **정답 보기** → **다음 문제 열기**.
   - "정답 여부·점수 보기"를 켜면 학생별 O/X와 점수가 보임 (화면을 TV에 띄울 때는 꺼 두기).
6. 마지막 문제 뒤 **결과 보기** → 순위·문항별 정답률. 학생 태블릿에도 각자 결과가 나옴.
7. **수업 끝내기** → 방과 기록(이름·답)이 Firebase에서 지워짐.

학생이 새로고침하거나 잠깐 연결이 끊겨도 같은 방으로 다시 들어오고, 이미 낸 답·보물 위치는 그대로입니다.
교사가 새로고침해도 진행 중인 방을 **이어서 진행**할 수 있습니다.

## 보물

- 보물 종류: 금화 +3, 루비 +5, 다이아몬드 +7, 왕관 +10 (점수가 높을수록 드물게). 꽝: 돌멩이·낡은 장화·빈 조개껍데기.
- 반 전체가 같은 보물판을 씁니다. 문제를 처음 열 때 무작위로 만들어집니다.
- 교사 화면 **보물 섞기**: 보물 위치와 종류를 새로 섞습니다. 그 뒤에 카드를 고르는 학생부터 적용되고, 이미 고른 학생의 결과는 그대로입니다.
- '정답 여부·점수 보기'를 켜면 교사 화면에 지금 보물판(카드별 보물·꽝)이 보입니다.
- 퀴즈 settings의 `cards`(카드 수), `treasures`(보물 개수), `treasureTypes`(보물 종류·점수·나오는 비율)로 바꿀 수 있습니다.

## 연습(데모) 모드

`firebase-config.js`가 비어 있으면 데모 모드입니다. 같은 컴퓨터·같은 브라우저에서
교사 탭과 학생 탭 여러 개를 열어 흐름을 미리 볼 수 있습니다 (교실 태블릿끼리는 연결 안 됨).
로컬에서 볼 때: 폴더에서 `python3 -m http.server` 후 `http://localhost:8000/teacher.html`.

## 새 퀴즈 넣기

1. `quizzes/새퀴즈.js` 작성 (형식은 처음 만든 퀴즈 앱과 같음: `const QUIZ = { id, title, subtitle, settings, questions }`).
   - type: `ox` / `choice` / `number` / `short`, 그림은 `figure: {w,h,grid,draw}` 또는 `image: "images/파일.png"`.
2. `python3 make_index.py` → 교사 화면 목록에 추가됨.
3. 사이트에 다시 올리기. 학생 주소는 그대로.

## Firebase 규칙

`database.rules.json` 내용: `rooms/<4자리 코드>` 아래만 읽고 쓸 수 있고 나머지는 막혀 있습니다.
방 코드를 아는 사람은 그 방에 들어올 수 있으므로, 수업이 끝나면 **수업 끝내기**로 기록을 지워 주세요.
무료(Spark) 요금제의 동시 접속 한도는 100명이라 한 반 수업에는 충분합니다.
