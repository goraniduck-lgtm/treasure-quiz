# 그림 기억 레이스

학생이 태블릿으로 제시어를 N초씩 그리고 → 순서가 섞인 내 그림의 제시어를 기억해서 맞히고 → 친구 그림을 보고 제시어를 맞히는 경주를 하는 수업용 웹앱.

- 학생: `index.html` (방 코드 + 번호로 입장)
- 교사: `index.html#teacher`
- 연습 모드: 주소 끝에 `?local` (같은 브라우저 탭끼리만 연결)
- 데이터: Firebase Realtime Database `rooms/<4자리 코드>` (보물 찾기 퀴즈와 같은 프로젝트·규칙 사용)

## 추가 기능
- 대기실 ⚙️ 바꾸기: 들어온 학생은 그대로 두고 제시어 목록·개수·시간·경주 모양 변경 (무작위 / 목록 순서대로, 앞 판 제시어 빼기)
- 교사 화면 위쪽 작은 학생 입장 QR (누르면 크게)
- 튕기거나 뒤로 간 학생: QR을 다시 찍거나 새로고침하면 같은 번호로 하던 곳에 돌아옴 · 뒤로 가기 버튼 막힘
- 학생 전체화면: 들어가기를 누르면 전체화면, 풀리면 '눌러서 계속하기' 화면 (설정에서 끌 수 있음)
