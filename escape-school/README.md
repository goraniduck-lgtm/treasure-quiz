# 달무리초 탈출

4학년 1학기 수학 복습용 분기형 인터랙티브 픽션. 학생 태블릿 1인 1기기, 10개 장면, 약 10분.

- 주소: `https://goraniduck-lgtm.github.io/treasure-quiz/escape-school/`
- 단원: 큰 수(2) · 각도(3) · 곱셈과 나눗셈(2) · 평면도형의 이동(1) · 막대그래프(1) · 규칙 찾기(1)
- 정답: 열쇠 조각 +2, 진짜 사람(동료) 합류 / 오답: 규칙서 힌트 → 비슷한 문제 재도전(+1) / 엉뚱: 동화 +1, 3번이면 동화 결말
- 5번째 장면 뒤 열쇠 조각 수로 길이 갈림: 8개 이상 정문, 4~7개 옥상, 3개 이하 지하
- 탈출 결말에 닿으면 마지막 갈림길: 그냥 나가거나, 심화 봉인 6문제(재도전 없음)에 도전. 6개 모두 맞히면 진 결말(14), 1개 틀리면 행복한 결말(15), 2개 틀리면 원래 탈출 결말
- 결말 15개(탈출 6 · 실패 2 · 동화 3 · 비밀 3 · 행복 1 · 진 1), 결말 도감은 태블릿 브라우저에 저장
- 문항·이야기는 `index.html`의 `SCENES`, 규칙서는 `BOOK`, 결말은 `ENDINGS`, 심화 봉인은 `HARD`
