# 달무리초 탈출

4학년 1학기 수학 복습용 분기형 인터랙티브 픽션. 학생 태블릿 1인 1기기, 10개 장면, 약 10분.

- 주소: `https://goraniduck-lgtm.github.io/treasure-quiz/escape-school/`
- 단원: 큰 수(2) · 각도(3) · 곱셈과 나눗셈(2) · 평면도형의 이동(1) · 막대그래프(1) · 규칙 찾기(1)
- 정답: 열쇠 조각 +2, 진짜 사람(동료) 합류 / 오답: 규칙서 힌트 → 비슷한 문제 재도전(+1) / 엉뚱: 동화 +1, 3번이면 동화 결말
- 5번째 장면 뒤 열쇠 조각 수로 길이 갈림: 8개 이상 정문, 4~7개 옥상, 3개 이하 지하
- 탈출 결말에 닿으면 마지막 갈림길: 그냥 나가거나, 심화 봉인 6문제(재도전 없음)에 도전. 6개 모두 맞히면 진 결말(14), 1개 틀리면 행복한 결말(15), 2개 틀리면 원래 탈출 결말
- 결말 15개(탈출 6 · 실패 2 · 동화 3 · 비밀 3 · 행복 1 · 진 1), 결말 도감은 태블릿 브라우저에 저장
- 문항·이야기는 `index.html`의 `SCENES`, 규칙서는 `BOOK`, 결말은 `ENDINGS`, 심화 봉인은 `HARD`

## 다회차 구조 (2026-10-20 개편)
- 난이도: 서로 다른 결말 0~2개 1단계, 3~5개 2단계, 6~8개 3단계, 9~11개 4단계, 12~15개 5단계 (`dalmuri-endings`)
- 문제: `TYPES` 단원별 5단계 유형 (예: 곱셈 1단계 식 → 2단계 문장제 → 3단계 두 단계 계산 → 4단계 불필요한 정보 → 5단계 두 결과 비교).
  회차 시작 때 만들어 저장하므로 새로고침·이어 하기에도 정답이 바뀌지 않음. 직전 회차와 같은 문제는 피함. 오답마다 '왜 틀렸을까' 설명.
- 경로: 5번째 장소 뒤 학생이 정문·옥상·지하를 직접 고름. 7번째 장소는 경로 전용 문제(정문 경비실 나눗셈, 옥상 시계탑 각도, 지하 계기판 규칙 찾기).
  들어갈 때 사건(정문 쇠사슬, 옥상 수위 아저씨, 지하 사다리), 9번째 장소 앞 두 번째 선택, 마지막 사건 카드에서 결말 이유를 보여 줌.
- 엔딩 판정 우선순위: 동화 3(E8·E9·E10) → 마지막 문 엉뚱+학교의 비밀(E13) → 전부 첫 정답(E12) → 경로 결말 → 동화 2면 E11 → 탈출 결말이면 심화 봉인(E14·E15)
  - 정문: 아이들 먼저 찾기+열쇠 16(경비실 열쇠 있으면 14)↑ E1, 열쇠 12(10)↑ E2, 나머지 E3
  - 옥상 열기구: (시계탑 비밀 또는 수위 아저씨 또는 동료 7명)+열쇠 10↑ E4, 아니면 E5 / 비상계단: 열쇠 12↑ E2, 나머지 E3
  - 지하: 열쇠 9(기록되지 않은 문 7, 배관 지도 있으면 −2)↑ E6, 아니면 E7. 사다리 사건: 열쇠 10↑이면 3개 잃음
- 힌트: 첫 결말 뒤부터 회차마다 못 찾은 결말의 수수께끼 쪽지 1장(이력 `dalmuri-meta`). 다 찾으면 축하 문구.
- 선생님 기록: 첫 화면 '선생님 기록' — 회차별 경로·결말·첫 정답/재도전/최종 오답·다시 볼 단원
